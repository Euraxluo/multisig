# Internal Working Records

These are working records produced during development: multi-perspective review notes, working prompts, and internal memos. They are kept for maintainers as historical evidence of how conclusions were reached — they are **not release material** and are superseded by the documents in the parent directory wherever the two disagree.

- `teams/` — Ten-perspective review notes from a parallel review pass: red-team (chain, crypto, UX), user (novice, member), developer (performance, API), fork, docs, and optimization.
- `PRODUCTION_PROMPT.md` — The working prompt that drove the production-readiness pass; recorded for reproducibility.
- `INVESTMENT_MEMO.md` — An internal investment memo assessing the project's state and prospects.

For the public-facing organization of documentation, see [`../README.md`](../README.md).
